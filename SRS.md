# Software Requirements Specification (SRS) for Boomgardi Platform

## 1. Introduction
- **Purpose**: The purpose of the Boomgardi Platform is to facilitate the booking and management of eco-lodge accommodations.
- **Scope**: This platform serves to connect guests seeking eco-friendly lodging with hosts offering unique accommodations.

## 2. Overall Description
- **Roles**:
  - **Guest**: Users who seek to book accommodations.
  - **Host**: Owners of eco-lodges who list their properties for booking.
  - **Admin**: Users that manage the platform, oversee bookings, and handle user accounts.

## 3. System Features
- **User Authentication**: Secure methods for users to register, log in, and manage accounts.
- **Accommodation Booking**: Functionality for guests to search, select, and book available accommodations.
- **Search & Filter**: Tools that allow users to filter accommodations based on various criteria (location, price, amenities, etc.).

## 4. Non-Functional Requirements
- **Security**: The platform must implement robust security measures to protect user data.
- **Performance**: The system should perform efficiently under load, ensuring a swift response time for users.
- **Reliability**: The platform must maintain high uptime, with swift recovery mechanisms in case of failure.
